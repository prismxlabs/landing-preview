# PRISM landing preview

A preview of the new PRISM landing page, hosted with GitHub Pages at https://prismxlabs.github.io/landing-preview/.
It is a static mock: plain HTML, CSS and JavaScript with no build step. The live site, prismxlabs.com, is
deployed separately from `prismxlabs/landing`.

- Hero film: Pexels footage edited for PRISM. Interior photos: Unsplash. Both licences allow commercial use.
- Icons: Lucide (ISC licence), inlined in `icons.js`.
- Product screenshots are taken from the PRISM dashboard.
